File format

  1. Start from the template, or use your own file with a header row naming the columns.
  2. Columns can be separated by commas, semicolons or tabs. Header names can use spaces or underscores, in any case.
  3. In Excel, save with File › Save As › CSV UTF-8 (Comma delimited) so that letters such as ā, č, ē and š are kept.
Required columns
  • name: up to 100 characters
  • category: matched by name; a new one is created if it doesn't exist
  • initial_value: a number such as 1249.00 or 1 249,00
  • responsible_person: up to 100 characters
  • registration_date: 2026-01-31 or 31.01.2026
Optional columns
  • location: matched by name; a new one is created if it doesn't exist
  • quantity: a whole number, 1 if left out

Other columns are ignored.
